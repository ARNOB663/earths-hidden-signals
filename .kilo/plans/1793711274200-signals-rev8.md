## Step A — commit 2 · Nov 7 · real data for all three tiles, one download each

1. `imerg.py`: robust `read_geotiff` (tiepoint-only files fall back to documented 0.1° / NW
   90N 180W and record the route; the current `px`/`py` pairing assertion is fixed), plus
   `fetch_day(day) -> path` with the ladder (Late → Early, version recorded, no mixing inside
   a window) caching under `scripts/signals/raw/` (gitignored). A day already on disk is never
   downloaded again (content-addressed filename + `--force` to override).
2. `tiles.py`: `cells_from_raster(raster, tile, cell_deg)` → per-cell mean; called for **all
   three tiles from the one raster** in a single pass (`all_cells_from_raster`).
3. `baseline/build_tile.py` (or `run.py --build-baseline`): stream one day at a time;
   extract all three tiles from that file; append to `scripts/signals/baseline/<tile>.npz`
   (float16 mm + mask, ≤8 MB each, total ≤25 MB) and `manifest.json` (`product:"late"`,
   startYear, endDate, years, sha256).
4. `run.py --time-one-day --lag-days 3`: print bytes, seconds, MB, valid fraction, cells for all
   three tiles, and projections at 1/4/8 workers for the full span. **>30 min per tile at 4
   workers → stop**, report, offer options (8 workers / later start year / fewer tiles / range
   requests / Actions runners).
5. Sanity check (§4b): 2–3 points on ≥1 heavy-rain day: IMERG vs NASA POWER (scale only) and one
   GHCN-Daily station (id, distance, units) → append to `spike_report.md`; any ratio outside
   0.3–3 ⇒ stop and fix before writing.
6. Full run for the three tiles → `engine.evaluate(basis="real")` → writers: `grid/<tile>.json`,
   `top.json`, `meta.json` (`basis:"imerg-late"`, real `measurementTime`, `sampleData:false`),
   `sources.json` (`imerg-late` ok, `checkedOn` today). `sample.assert_no_mixing(False, …)` and
   `staleHours` freshness enforced before writing.
7. Tests: loader fixtures (tiny synthetic GeoTIFF, tiepoint-only variant), one-pass three-tile
   extraction equals per-tile extraction, no re-download, manifest/product check, tile bounds on
   real grid, writers/budgets. Full validation suite.

Proposal includes the timing table (sec/day, MB/day, projected total, PASS/STOP):
"approve commit 2 (real Bengal delta, Indus plain, Western Himalaya)?"
